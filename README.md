# Conzen.ai Investor Website

Static investor website for Conzen.ai. The site is designed to be hosted directly on GitHub Pages with no backend, build step, package install, or external runtime dependency.

## Files

- `index.html` - main website page
- `styles.css` - responsive visual system and layout
- `script.js` - mobile navigation and reveal behavior
- `assets/` - local logos, palette reference, and team images

## Deploy On GitHub Pages

1. Push this folder to a GitHub repository.
2. In GitHub, open **Settings > Pages**.
3. Set the source to the repository branch and root folder.
4. Save. GitHub Pages will serve the site over HTTPS.

Contact links use `mailto:mingfong@conzen.ai`, so no server-side form processing is required.
